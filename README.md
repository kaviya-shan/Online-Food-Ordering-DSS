# Online-Food-Ordering-DSS
Online Food Ordering Prediction using Machine Learning

📘 Project Overview
This project is a Decision Support System (DSS) that predicts whether a customer will place a future food order using Machine Learning.
It combines a C4.5 Decision Tree model and a Flask web interface to make real-time predictions based on user inputs like taste, offers, and convenience.

🧩 Features
*Predicts if a user will purchase or will not purchase food online.
*Flask-based web interface for easy interaction.
*Machine Learning model trained using Decision Tree (entropy-based).
*Modular code for training and prediction.

🧠 Tech Stack
*Python 3.x
*Flask
*Scikit-learn
*Pandas, NumPy
